# Why the register has no front end

The work is deciding which revision is current, who owes a review and who received an older drawing. The database keeps these relationships and the coding agent runs the commands. Read-only HTML gives the team a register, handover watch and design-information checklist.

This build does not edit CAD files, render drawing geometry, capture mobile markups, synchronize offline changes or provide a drag-and-drop review screen. It stores references to files held in your controlled archive. Open and assess those files with the engineering tools your team already uses. Local fictional demo files are labelled placeholders.

Enterprise DNA can scope a web view, mobile capture, archive connection or other interface for your version. These are separate implementation work, not features of this free register. If your daily work depends on interactive drawing markup, keep that workflow in your existing tool until its replacement has been built and tested.
